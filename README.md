# Rovaniemi - Snow Cover Analysis (Sentinel-2 & ERA5)

This **Earth Observation (EO)** project studies the **temporal and spatial evolution** of snow cover around **Rovaniemi, Lapland (Finland)** using **Sentinel-2 L2A** data (Copernicus Data Space) and **ERA5** reanalysis data.

The pipeline is orchestrated by `main.py`, which chains together data acquisition, exploratory analysis, preprocessing, and dataset merging. The notebooks complement the workflow with visual analysis and machine learning experiments.

## Project Architecture

```text

└── figures/                # Figures generated by the pipeline
```

## Data Pipeline (Medallion)

| Stage | Folder / output | Description |
|-------|------------------|-------------|
| **Bronze** | `data/NetCDF/` | Sentinel-2 L2A download via OpenEO (one NetCDF file per winter season) |
| **Silver** | `df_Sentinel_silver.csv` | Cleaned Sentinel data with cloud masking, NDSI, and daily aggregation |
| **Gold** | `df_Sentinel_ERA5_gold.csv` | Merged Sentinel + ERA5 dataset for feature analysis |
| **Gold ML** | `df_Sentinel_ERA5_ML_gold.csv` | Merged dataset prepared for the ML notebook |

## Folders and Features

### `data/` - Acquisition

- **`Sentinel_data_loading.py`**: connects to the [OpenEO Copernicus API](https://openeo.dataspace.copernicus.eu), performs OIDC authentication, downloads Sentinel-2 L2A data (bands B03, B11, SCL) for the Rovaniemi area, and exports NetCDF files to `data/NetCDF/`.
- **`data_acquisitions.txt`**: log of the number of acquisitions for each winter season (2017-2026).

Study area (bounding box): `west=25.7, south=66.48, east=25.75, north=66.52`.

### `EDA/` - Exploratory Data Analysis

- **`number_of_acquisitions.py`**: counts Sentinel acquisitions for each winter and generates figures in `figures/EDA/number_of_acquisitions/`.
- **`EDA.py`**: computes data quality metrics (NaN, bad, and cloudy pixels using the SCL band), descriptive statistics, and the cloud mask used during preprocessing.
- **`EDA_figure.ipynb`**: companion notebook for EDA visualizations.

### `preprocessing/` - Preprocessing

- **`utils.py`**: converts UTM coordinates to latitude/longitude, applies cloud masking, and computes the **NDSI** `(B03 - B11) / (B03 + B11)`.
- **`preprocessing.py`**:
  - Sentinel workflow: coordinate conversion, time feature extraction, cloud filtering, NDSI computation, and daily aggregation (`ndsi_median`, `ndsi_mad`, `snow_fraction` with an NDSI threshold of `0.42`).
  - ERA5 workflow: merges precipitation, skin temperature, and snow depth data, then aligns them to the winter season timeline (November to April).

### `features_analysis/` - Visualization

- **`features_analysis.ipynb`**: time series analysis, spatial snow evolution, and interactive HTML exports stored in `figures/features_analysis/`.

### `ML/` - Machine Learning

- **`ML_notebook.ipynb`**: modeling experiments based on the gold ML dataset; outputs are saved in `figures/ML/`.

### `figures/` - Graphical Outputs

Mirror structure of the main stages: `EDA/`, `pre_processing/`, `features_analysis/`, `ML/`.

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

### API Credentials Setup

1. Copy the template: `copy credits.example.py credits.py`
2. Fill in your OpenEO Copernicus credentials in `credits.py`.

## Run the Pipeline

From the project root:

```bash
python main.py
```

Commented sections in `main.py` include:

- Sentinel download loop (2017-2025),
- acquisition counting,
- EDA + preprocessing + ERA5 merge (enabled by default).

If needed, update the absolute Windows paths in `main.py`, or replace them with relative paths based on `Path(__file__).parent`.

## Main Dependencies

OpenEO, xarray, pandas, numpy, matplotlib, seaborn, scipy, pyproj, IPython, scikit-learn.

## Data

Large files (NetCDF, bronze/silver CSV files) are **not** versioned on GitHub. They should either be regenerated through the pipeline.
